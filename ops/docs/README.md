# Operations Toolkit

The Operations Toolkit is a collection of Bash utilities for managing and
diagnosing my self-hosted infrastructure.

## Philosophy

The toolkit is designed around a few simple engineering principles rather than
complex frameworks.

- KISS (Keep It Simple, Stupid)
- DRY (Don't Repeat Yourself)
- Single Responsibility
- Build for today's requirements
- Explain why, not what
- Make failures useful

The goal is to produce reliable, readable and maintainable code that can be
understood and extended months or years later.

## Versioning

The Operations Toolkit follows Semantic Versioning.

- MAJOR: Breaking architectural changes.
- MINOR: New features or subsystems.
- PATCH: Bug fixes and maintenance.
